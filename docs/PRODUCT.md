# Produto

**SessionFlow** é um gerenciador desktop universal de sessões de agentes de programação. Ele lê os históricos locais do Claude Code, do OpenAI Codex e do OpenCode, e permite descobrir, organizar (projetos, favoritos, tags), pesquisar, visualizar e retomar sessões na CLI original.

## Princípios
- **Local e privado:** funciona offline, sem telemetria e sem enviar históricos a nenhum serviço.
- **Somente leitura:** nunca modifica nem apaga os históricos originais.
- **Tolerante:** a falha de um provider ou um arquivo malformado não derrubam o app.
- **Simples:** poucas dependências; o código é simples de manter antes de ter muitas funcionalidades.

## Público
Desenvolvedores que usam um ou mais agentes de programação em vários projetos e perdem o rastro de conversas antigas.

## Interface
Desktop dark por padrão, com sidebar (Dashboard, Sessões, Projetos, Favoritas, Busca, Configurações), área principal e painel de detalhes. As referências são Linear, Raycast, Cursor e VS Code. A interface está em pt-BR.
